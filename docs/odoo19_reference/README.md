# Odoo 19.0 Developer Reference – lokale Markdown-Kopie

- Quelle: https://www.odoo.com/documentation/19.0/de/developer/reference.html (Bereich *Reference*, alle Unterseiten)
- Abgerufen: 2026-10-02, Version 19.0 (Seiten sind englisch, die Navigation deutsch)
- Umwandlung: HTML → Markdown per Skript (Codeblöcke, Tabellen, Hinweisboxen, API-Signaturen erhalten; Navigation, Bilder und Fußzeilen weggelassen)
- Struktur: Pfade entsprechen den URLs der Originalseite. Seiten über 1500 Zeilen sind an H2-Überschriften in Ordner mit nummerierten Teilen aufgeteilt (`backend/orm/`, `user_interface/view_architectures/`, `frontend/unit_testing/hoot/`, `upgrades/upgrade_utils/`); kleine Abschnitte sind mit dem Nachbarn zusammengefasst, Dateiname = erster__letzter Abschnitt.
- Zusätzlich: `contributing/coding_guidelines.md` (Odoo Coding Guidelines 19.0, Volltext; stammt aus Contributing → Development).
- Verbindliche Regeln stehen NICHT hier, sondern als Destillate in `docs/odoo_regeln/`. Dieser Ordner ist nur zum Nachschlagen.
- Einstieg: `INDEX.md`. Jede Datei beginnt mit einem Kommentar mit der Quell-URL.
- Aktualisieren: Seiten neu abrufen und überschreiben; Skripte lagen nur temporär in der Sitzung (nicht im Repo).
